# Inside the visual catalog

Open a [catalog DOCX](catalog.md) and search for a numbered heading or feature label.

| Heading | What to look for |
| --- | --- |
| 01 Paragraphs | Heading levels 1–9, alignment, spacing, tab stops. The edited copy centers the `Imported editor:` paragraph and inserts a two-column table after it. |
| 02 Runs | Fonts, colors, underline styles, Unicode, script direction and explicit false overrides. |
| 03 Styles | Linked paragraph/character styles, inheritance and direct formatting. |
| 04 Tables | Nested tables, widths, merges, cell margins, vertical text, repeating headers and row heights. |
| 05 Conditional styles | Whole-table formatting, first/last rows and columns, banding and corner cells. |
| 06 Lists and references | Multilevel lists, restarts, links, bookmarks, comments, notes, fields, tracked changes and content controls. Open the comments pane to see review text. |
| 07 Drawings | Images, crops, wrapping, shapes, text boxes, a column chart and a stacked fraction. |
| 08 Authoring | Conditional content and text from deferred values. |
| 09 Sections | Orientation, margins, columns, headers/footers, line numbering, grids and page borders. |

The [Rust](https://github.com/ReinderVosDeWael/rocx/blob/main/examples/all_features.rs), [Python](https://github.com/ReinderVosDeWael/rocx/blob/main/examples/all_features.py) and [JavaScript](https://github.com/ReinderVosDeWael/rocx/blob/main/examples/javascript/catalog.mjs) sources show how to author the samples. Page numbers and field display depend on your viewer.
