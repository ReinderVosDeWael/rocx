# Viewer compatibility

LibreOffice Writer 25.8.7.3 on Ubuntu 25.10 opened the four sample files below. No repair dialog was visible in the inspected views. **Desktop Word, save/reopen and field refresh were not tested.** Page counts, fonts and field values may differ in your viewer.

| Sample | Visible in Writer |
| --- | --- |
| Quickstart | Both paragraphs, including accented text and the globe emoji. |
| Compact python-docx document | Heading, Unicode text, 2 × 2 table, bullets and an inline image. |
| Visual catalog | Labeled left-aligned paragraph followed by heading samples. |
| Edited catalog | Centered paragraph and inserted two-column table; first/even/default headers, linked text, image, page-number footer, style samples and a shaded merged cell. |

The edited catalog's updated style label was readable, but its stated bold/italic combination was not visually confirmed. Charts, floating objects, revisions and controls were not inspected. See the [visual catalog](https://reindervosdewael.github.io/rocx/catalog/) to try your own viewer.
